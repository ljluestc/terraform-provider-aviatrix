### 2.2.2 Workflow Jobs

**Job 1: changes**
- Detects which files changed using dorny/paths-filter
- Outputs: relevant_files, go_files, test_files
- Enables smart test execution

**Job 2: unit-tests**
- Matrix: Go 1.23, 1.24
- Go module caching for performance
- Flags: -v, -race, -timeout, -coverprofile, -covermode=atomic
- Generates: coverage.out, coverage.xml, coverage.html, JUnit XML
- Publishes results via EnricoMi/publish-unit-test-result-action
- Artifacts uploaded with 30-day retention

**Job 3: docker-build**
- Matrix: [builder, test, production, ci-test]
- Uses Docker Buildx with layer caching
- Saves images as tar artifacts
- Validates all build stages

**Job 4: integration-tests**
- Matrix: [aws, azure, gcp, oci]
- Depends on: docker-build
- Loads Docker image from artifacts
- Mounts test volumes
- Timeout: 3600 seconds (1 hour)
- Provider-specific environment variables
- Artifact collection per provider

**Job 5: security-scan**
- Tool: Gosec security scanner
- Output: SARIF format
- GitHub Code Scanning integration
- Automated vulnerability detection

**Job 6: test-summary**
- Aggregates all job results
- Generates GitHub Step Summary
- Reports test counts and failures
- Coverage information included
